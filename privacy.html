1. 개인정보 수집 및 서버 전송 여부

본 서비스(파이어족 몬테카를로 은퇴 생존확률 시뮬레이터)는 회원가입 절차 없이 무료로 이용할 수 있는 정적 웹 도구입니다. 사용자가 화면에 입력하는 순자산, 월 저축액, 연령, 월 생활비, 추가 고정수입, 수익률 등 모든 시뮬레이션 입력값은 외부 서버나 데이터베이스로 전송·저장되지 않으며 오직 사용자 기기의 웹 브라우저 내부에서만 로컬로 연산됩니다.

2. 브라우저 로컬 저장소(localStorage · sessionStorage) 및 URL 해시 안내

  • 로컬 저장소(localStorage): 재방문 또는 심화 스트레스 테스트 페이지 이동 시 입력값을 다시 적는 번거로움을 줄이기 위해 사용자 브라우저의 localStorage(키 이름: kr_fire_mc_state_v1)에 최근 입력 조건을 임시 보관합니다. 브라우저 인터넷 사용 기록(사이트 데이터)을 삭제하거나 화면의 ‘초기화’ 버튼을 누르면 언제든 초기 상태로 되돌릴 수 있습니다.
  • 세션 저장소(sessionStorage): 심화 리포트 열람 상태를 현재 브라우저 탭 세션 동안 유지하기 위해 sessionStorage 플래그만 사용하며 탭 종료 시 자동으로 소멸합니다.
  • 공유 링크(URL 해시): 사용자가 직접 ‘링크 복사’ 또는 ‘공유’ 버튼을 눌렀을 때만 입력 파라미터가 주소 뒷부분 해시(#s=...) 문자열로 인코딩됩니다. ‘자산 총액 숨김’ 옵션을 활성화하면 실제 순자산 및 생활비 금액은 공유 해시에서도 제외됩니다.

3. 쿠키(Cookie) 및 제3자 광고 서비스 안내

본 사이트는 서비스 운영 및 무료 유지를 위해 Google AdSense 등 제3자 광고 플랫폼을 사용할 수 있습니다.

  • Google을 포함한 제3자 광고 사업자는 사용자의 본 사이트 및 타 사이트 방문 기록을 바탕으로 맞춤형 광고를 제공하기 위해 쿠키(광고 식별자)를 사용할 수 있습니다.
  • 사용자는 브라우저 설정을 통해 쿠키 저장을 거부하거나 삭제할 수 있으며, Google 광고 설정 페이지에서 개인 맞춤형 광고 노출을 직접 해제할 수 있습니다.

4. 외부 라이브러리 및 공유 연동

차트 시각화(Chart.js), PDF 문서 생성(jsPDF), 카카오톡 메시지 공유(Kakao JavaScript SDK) 기능을 실행할 때 해당 공식 콘텐츠 전송 네트워크(CDN)로 스크립트 요청이 발생할 수 있으나, 사용자의 시뮬레이션 자산 원본 데이터를 별도 수집 서버로 업로드하지 않습니다.

5. 방침 변경 및 문의

본 개인정보처리방침의 내용이 기능 변경 등으로 수정될 경우 본 페이지를 통해 고지합니다. 서비스 관련 문의 사항은 서비스 소개 및 문의 페이지의 안내 채널을 이용해 주시기 바랍니다.
