1. 왜 이 시뮬레이터를 만들었나요?

많은 은퇴 자금 계산기가 “연평균 7% 복리”처럼 매년 흔들림 없는 직선 수익률을 가정합니다. 하지만 실제 은퇴 생활에서는 평균 수익률이 같더라도 은퇴 직후 1~3년 사이에 하락장을 먼저 겪으면 원금이 빠르게 소진되는 수익률 순서 위험(Sequence of Returns Risk)이 발생합니다. 본 시뮬레이터는 복잡한 스프레드시트나 유료 프로그램 없이도 누구나 웹 브라우저에서 즉시 수천 번의 확률 시뮬레이션을 돌려보고, 폭락장과 인플레이션이 겹치는 스트레스 상황을 객관적인 백분위수 궤적으로 점검할 수 있도록 제작되었습니다.

2. 투명하게 공개하는 연산 원리

  • 난수 생성 모델: 박스-뮬러 변환(Box-Muller Transform)을 사용하여 표준정규분포 Z ~ N(0, 1)를 따르는 독립 난수를 생성하고, 입력된 기대수익률과 표준편차를 결합해 연도별 수익률을 산출합니다.
  • 현금흐름 반영: 은퇴 전에는 월 저축액의 연간 적립을 반영하고, 은퇴 후에는 max(0, 은퇴 후 월 생활비 - 추가 고정수입) × 12에 연간 물가상승률을 누적 적용하여 순인출액을 차감합니다.
  • 고속 로컬 처리: 메인 페이지에서는 Float64Array 메모리 버퍼를 통해 2,000회 경로를 수십 밀리초 이내에 계산하며, 심화 페이지에서는 Web Worker 백그라운드 스레드로 10,000회 경로와 복합 스트레스 매트릭스를 UI 멈춤 없이 처리합니다.
  • 프라이버시 중심 설계: 입력된 자산 숫자는 외부 서버로 전송되지 않으며, SNS 공유 시에도 자산 금액을 숨기고 생존확률·등급·인출률만 표시하는 비공개 모드를 기본 제공합니다.
